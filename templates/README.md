# Vorlagen

Vorlagen sind ausfüllbare Hilfen. Unzutreffende optionale Abschnitte entfernen; keine leeren Pflichtzeremonien erzeugen. Platzhalter vor Verwendung ersetzen. Normative Regeln stehen im [Workflow](../rules/WORKFLOW.md); eine Vorlage erteilt keine zusätzliche Befugnis.

| Vorlage | Verwendung |
| --- | --- |
| [Issue](ISSUE.template.md) | Fehler, Feature oder Paket, bei Bedarf mit mehreren benannten Paketen |
| [PR](PULL_REQUEST.template.md) | Umsetzung und tatsächliche Prüfnachweise |
| [Review](REVIEW.template.md) | Commitgebundenes Urteil und konsolidierte Befunde |
| [Projektprofil](PROJECT_PROFILE.template.md) | Konkrete Befehle, Grenzen und Abnahme im Zielrepository |
| [AGENTS](AGENTS.template.md) | Kurzer Einstieg; mit vorhandenen Agentenregeln zusammenführen |
| [ChatGPT-Projekteinstellungen](CHATGPT_PROJECT_INSTRUCTIONS.template.md) | Kompakter Einstieg in die repositorybasierten Regeln |
| [Übergaben](HANDOFFS.md) | Kurze kopierbare Arbeitsaufträge nach abgeschlossener Vorbereitung |

Dateien mit `*.template.md` werden nicht als echte `AGENTS.md` eingecheckt, solange sie nur Beispiele sind. Die komplette Vorlagensammlung ist keine Pflichtlektüre eines ausführenden Agenten.

Bei Einführung können Issue-/PR-Vorlagen ausdrücklich in GitHubs Vorlagenpfade übernommen werden. Bereits vorhandene Templates vorher abgleichen; nicht mehrere unabhängig gepflegte Versionen derselben Vorlage aktivieren.
